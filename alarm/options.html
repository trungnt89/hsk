Cài Đặt Hệ Thống & Đồng Bộ

Quản lý Assistive, Google Sheets, Token và Dữ liệu cục bộ

1

Setting Token (Đồng Bộ Google Sheets & Azure TTS)

Thiết lập Token Authorization để kích hoạt đồng bộ dữ liệu đám mây và phát giọng đọc trực tuyến cao cấp.

Spreadsheet ID: 1HNJrXP3...NDuc Sheet: Sheet1 Chưa có Token

Token được lưu an toàn trong trình duyệt (localStorage & chrome.storage.local) và dùng chung cho toàn bộ hệ thống.

2

Dữ Liệu & Sao Lưu (Backup & Khôi Phục)

Sao lưu dữ liệu mốc báo thức ra file JSON, khôi phục hoặc xóa toàn bộ dữ liệu cục bộ.

📥 Xuất File JSON (Backup)

Tải xuống toàn bộ mốc báo thức để lưu trữ hoặc chuyển sang máy tính khác.

📤 Nhập File JSON (Restore)

Khôi phục danh sách mốc báo thức từ file sao lưu JSON trước đó.

3

Hiển Thị Assistive Touch (Nút Nổi Màn Hình)

Bảng điều khiển báo thức nổi trực tiếp trên trang web và cấu hình chế độ chạy ngầm.

Hiển thị Assistive Touch trên màn hình

Tự động nhúng bảng điều khiển báo thức nổi trực tiếp lên trang web đang duyệt để tiện theo dõi và thao tác.

💡 Bạn cũng có thể bật/tắt nhanh tùy chọn này ngay tại biểu tượng Extension trên thanh công cụ trình duyệt (Popup).
🛡️

Chế độ chạy ngầm khi đóng trình duyệt Chrome

Tiện ích đã được tích hợp quyền background trong Chrome Manifest V3.

Để đảm bảo báo thức reo và tự động bật lại trình duyệt kể cả khi bạn bấm "X" tắt sạch các cửa sổ:

  1. Mở chrome://settings/system trong Chrome.
  2. Bật tùy chọn: "Tiếp tục chạy các ứng dụng nền khi Google Chrome đã đóng".
